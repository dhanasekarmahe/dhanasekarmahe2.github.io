# Shafeeq Ayman N — 3D Salesforce Portfolio

A professional, dark-mode, animated portfolio for Shafeeq Ayman N — Senior Software Engineer, Salesforce.

## Included
- Actual profile photo at `public/assets/profile.jpg`
- Resume at `public/assets/Shafeeq-Ayman-N-Resume.pdf`
- 3D Three.js / React Three Fiber hero scene
- Framer Motion interactions
- Responsive mobile design
- Experience, expertise, certifications, education and achievements
- Public-safe contact links

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Free hosting

This is a static Vite site. It can be deployed to GitHub Pages, Vercel or Cloudflare Pages.
